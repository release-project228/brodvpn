# brodvpn

Privacy-focused VPN service: secure connection for apps on iOS, Android and
Windows.

**Website: [https://brodvpn.com](https://brodvpn.com)**

## Example

`probe.py` checks TCP reachability of hosts — a small network diagnostic,
the kind of utility that complements a VPN service:

```bash
python probe.py 1.1.1.1:443 8.8.8.8:53
```

The full service lives at [https://brodvpn.com](https://brodvpn.com).
